8.3 Goniometrische vergelijkingen

Los vergelijkingen exact op met de eenheidscirkel en onderzoek hoe de tangensgrafiek verandert.

EenheidscirkelOplosregelsTangensgrafiekOefenen

1. Bekijk de oplossingen op de eenheidscirkel

De sinus is de verticale coördinaat, de cosinus de horizontale. Een horizontale of verticale lijn laat zien welke punten dezelfde functiewaarde hebben.

2. Van draaihoek naar alle oplossingen

In alle oplossingsformules is k een geheel getal. Los eerst op voor de hele hoek A en reken daarna terug naar x. Deel bij het isoleren van x ook de term met k door de factor vóór x.

Sinus en cosinus gelijk aan −1, 0 of 1

sin(A) = 0 geeft A = kπ. Bij sin(A) = 1 of −1 krijg je respectievelijk A = π/2 + 2kπ of A = 3π/2 + 2kπ.

cos(A) = 0 geeft A = π/2 + kπ. Bij cos(A) = 1 of −1 krijg je respectievelijk A = 2kπ of A = π + 2kπ.

Voorbeeld. Bij cos(3x) = 0 geldt 3x = π/2 + kπ, dus x = π/6 + kπ/3.

Exacte waarden en oplossingen op een interval

Bij sin(A) = sin(B) geldt A = B + 2kπ of A = π − B + 2kπ. Bij cos(A) = cos(B) geldt A = B + 2kπ of A = −B + 2kπ.

Voorbeeld. Uit 2sin(2x) = √2 volgt 2x = π/4 + 2kπ of 2x = 3π/4 + 2kπ. Dus x = π/8 + kπ of x = 3π/8 + kπ. Op [0, π] krijg je π/8 en 3π/8.

Gebruik dezelfde regels als B zelf van x afhangt. Uit sin(2x) = sin(x) volgt 2x = x + 2kπ of 2x = π − x + 2kπ. Dat geeft x = 2kπ of x = π/3 + 2kπ/3.

Machten en producten

Herleid tot een product dat gelijk is aan nul. Uit cos²(x) − cos(x) = 0 volgt cos(x)(cos(x) − 1) = 0. Los cos(x) = 0 en cos(x) = 1 afzonderlijk op.

Tangensvergelijkingen en het domein

tan(A) = tan(B) geeft A = B + kπ, mits beide tangensen bestaan. Tangens is ongedefinieerd bij A = π/2 + kπ.

Voorbeeld. Uit tan(3x) = √3 volgt 3x = π/3 + kπ, dus x = π/9 + kπ/3.

3. Verken de tangensgrafiek

Op de eenheidscirkel is tan(A) = sin(A)/cos(A). Als cos(A) nul wordt, heeft de tangensgrafiek een verticale asymptoot.

y = a + b · tan(c(x − d))

Oranje punt: beginpunt (d, a). Gestreepte lijnen: asymptoten. Los c(x − d) = π/2 + kπ op om hun ligging te vinden.

4. Oefen met exacte oplossingen

Vul de gevraagde coëfficiënten exact in als geheel getal of breuk, bijvoorbeeld 5/6. Bij losse oplossingen maakt de volgorde niet uit.
