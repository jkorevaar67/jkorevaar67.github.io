Theory A

Read a graph carefully

A graph shows how two quantities are related. A point has two coordinates: the horizontal value comes first, then the vertical value. Always include the units when describing what a point means.

  1. Read both axis labels. Check which quantity is horizontal and which is vertical.
  2. Check the scale. Equal grid intervals on one axis must represent equal steps. The two axes may use different scales.
  3. Read across and up. Start at the horizontal value, move to the line, then read the corresponding vertical value.
  4. Explain the meaning. For example, (2, 40) on a time–distance graph can mean 40 metres from home after 2 minutes.

Worked example · A journey

A shortened vertical axis

Sometimes all measurements are near a large value, such as a baby's mass near 3000 g. The graph may start the vertical scale above zero. A zigzag or a clear note marks this. Count from the labelled starting value, not from zero.

Clock time is not elapsed time. If a phone is unplugged at 07:00, then 4 hours later is 11:00. On a graph labelled “time since unplugging”, use x = 4.

Theory B

From table to graph

Each column of a table gives a pair of values. Turn that pair into a point. First choose scales that fit all the data and still leave the graph easy to read.

  1. Draw the horizontal axis for the quantity in the first row. Draw the vertical axis for the quantity in the second row.
  2. Choose sensible, evenly spaced tick marks. For example, 12 hours at 3 hours per square needs 12 ÷ 3 = 4 squares.
  3. Label both axes with the quantities and their units.
  4. Plot every pair (horizontal value, vertical value).
  5. Join points in horizontal order if the context calls for a continuous graph. For a gradually changing natural quantity, use a suitable smooth curve. Use straight-line sections when a straight-line model is specified. Do not join unrelated categories.

Worked example · Plant height

The dots are the measured values. The straight segments in this example are a simple model between measurements. They do not prove how the plant grew between those measurements.

Check the size of each change. To find growth during a week, subtract the height at the start of that week from the height at the end. The highest point does not automatically show the largest weekly growth.

Theory C

Rough graphs: describe the relationship

A rough graph is mainly about the pattern of change. It usually has labelled axes without numbered scales, so exact values cannot be read.

IncreasingThe graph goes up as you read from left to right.
DecreasingThe graph goes down as you read from left to right.
ConstantThe graph is horizontal: the vertical quantity does not change.

The vertical label changes the meaning

  • On a speed–time graph, a horizontal section means constant speed. The traveller stops only if the speed is zero.
  • On a height–time graph, a falling section means descending. A horizontal section means staying at the same height, which does not necessarily mean standing still.
  • On a distance-from-home–time graph, a falling section means getting closer to home. A steep section represents a faster change in distance.

Filling a container

With a steady inflow, the same volume of water arrives each second. The shape of the container determines how quickly the water level rises.

A cylinder has the same width throughout, so its water level rises at a constant rate: a straight rising height–time graph. A wider part fills with a slower rise in height; a narrower part gives a faster rise.

Challenge

Compare two journeys

Show the worked solution

At an intersection, both graphs have the same vertical value at the same horizontal value. For distance–time graphs on the same route, that can mean the travellers meet.
